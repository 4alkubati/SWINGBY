# `autoDeploy: true` on Render. So the deployed dependency set was whatever

# commit could ship different code. A dependency that floats is a deploy that

# because the point is reproducibility: a range reintroduces the same drift
# more slowly. Dependabot (.github/dependabot.yml) proposes the bumps, and CI
# is what decides whether they land.
#
# Upgrading: change the pin, run the suite, commit both together.
